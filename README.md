# 🔢 GUI Calculator in Python

A simple yet elegant **GUI Calculator** built using Python's `tkinter` library — perfect as a beginner project to understand GUI development in Python.

## ✨ Features

✅ Clean and responsive user interface  
✅ Perform basic arithmetic operations (➕ ➖ ✖️ ➗)  
✅ Real-time input and result display  
✅ Built with minimal code and modular functions  
✅ Beginner-friendly — easy to understand and extend

## 🛠️ Technologies Used

- **Python 3**
- **Tkinter** – Python's built-in GUI package
  
## 🚀 Run the App
### Open Terminal / Command Prompt
- Navigate to the folder where your `calculator.py` file is located, and write
- python calculator.py
